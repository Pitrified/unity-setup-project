# Development Environment Setup

## 1. Goal

Zero → working local Android build in **under one hour**, without surprises.

Mental model:

```
clone → install Unity 6 LTS via Hub → open → run on device
```

## 3. First clone

Git LFS must be installed before cloning. [Installation guide](https://docs.github.com/en/repositories/working-with-files/managing-large-files/installing-git-large-file-storage).

```bash
git lfs install                # one-time, machine-wide
git clone <repo-url>
cd artificial-pi
git lfs pull                   # ensure binary assets are real files, not pointers
```

If the project opens with corrupt textures/models → `git lfs pull` was skipped.

---

## 4. Open in Unity

1. On first launch, Unity Hub will prompt for sign-in. Use **Google SSO** (or Unity ID) and accept a free **Unity Personal** license.
2. Unity Hub → **Add project from disk** → select the cloned folder.
3. Hub will show the required Editor version (`6000.4.4f1`). Install it if missing (see §9 for required modules).
4. Open. First import takes several minutes.

Expected on first open:

- 0 console errors.
- 0 missing script warnings.
- Boot scene auto-loads.

---

## 5. Local play loop (Editor)

1. Open `Assets/Scenes/Boot.unity`.
2. Press Play.
3. Bootstrap → Persistent → Menu → Game flow runs.

If you opened `Game.unity` directly, use the editor helper
**Tools → Load Persistent Scene** (provided in `Game.Editor` asmdef) before pressing Play.

## 6. Local Android build

One-time:

1. Enable **Developer Options** on the device (tap *Build number* 7 times in **Settings → About Phone**).
2. Under Developer Options, enable **USB debugging**.
3. Plug in via USB; when the transfer mode notification appears, tap it and select **File Transfer (MTP)**.
4. Accept the **Allow USB debugging** prompt that appears on the device screen.
5. Verify the device is listed (Unity bundles `adb`; see §9 for PATH setup):
   ```
   ~/Unity/Hub/Editor/6000.4.4f1/Editor/Data/PlaybackEngines/AndroidPlayer/SDK/platform-tools/adb devices
   ```
6. Copy `build.env.example` → `~/.config/artificial-pi/build.env`, fill in
   debug keystore values (debug keystore is auto-generated by Unity on first build).

Per-build:

```
./Tools/build-android.sh dev
adb install -r Build/dev.apk
adb logcat -s Unity:V
```

## 8. Common issues

| Symptom                                     | Likely cause / fix                                   |
| ------------------------------------------- | ---------------------------------------------------- |
| Pink/purple materials                       | URP not active or shaders not imported → Reimport All |
| Files show as text pointers (`oid sha256:`) | `git lfs pull` not run                               |
| Build fails with "Gradle"                   | Reinstall Android module via Unity Hub               |
| `adb` doesn't see device                    | USB debugging off, wrong cable, missing OEM driver   |
| "Multiple precompiled assemblies"           | Duplicate package in `Packages/manifest.json`        |
| Long iteration on script change             | Missing `.asmdef` boundary - see [project-structure.md](project-structure.md) |
| `adb: command not found`                    | `adb` is not on the system PATH; use the Unity-bundled path or add to PATH - see §9 |

## 9. Linux setup notes

### Unity Hub
Install following the [official Linux guide](https://docs.unity.com/en-us/hub/install-hub-linux). Launch from the terminal with `unityhub`.

On first launch, sign in with **Google SSO** (or Unity ID) and accept a **Unity Personal** license (free, covers all features needed for this project).

### Unity Editor modules
When installing the editor via Hub, select these modules:

| Module                       | Required?   | Notes                                                    |
| ---------------------------- | ----------- | -------------------------------------------------------- |
| Android Build Support        | Yes         |                                                          |
| OpenJDK                      | Yes         | Unity-managed; do not mix with a system JDK              |
| Android SDK & NDK Tools      | Yes         | Unity-managed; do not mix with Android Studio's SDK      |
| Linux Build Support (IL2CPP) | Recommended | Lets you run builds on Linux without deploying to device |

### ADB
Unity bundles its own Android SDK. The `adb` binary is **not** on the system PATH by default. Full path:

```
~/Unity/Hub/Editor/6000.4.4f1/Editor/Data/PlaybackEngines/AndroidPlayer/SDK/platform-tools/adb
```

Add it to PATH once (e.g. in `~/.bashrc`):

```bash
export PATH="$HOME/Unity/Hub/Editor/6000.4.4f1/Editor/Data/PlaybackEngines/AndroidPlayer/SDK/platform-tools:$PATH"
```

Also ensure `udev` rules are configured for your device (e.g. `/etc/udev/rules.d/51-android.rules`).

### bundletool
Used to locally install and test release AAB files without uploading to Play Console.

1. Download the latest `bundletool-all-x.y.z.jar` from the [GitHub releases page](https://github.com/google/bundletool).
2. Rename it to `bundletool-all.jar` and place it somewhere stable (e.g. `~/tools/`).
3. Add an alias to your shell profile (`~/.bashrc` / `~/.zshrc`):
   ```bash
   alias bundletool='java -jar ~/tools/bundletool-all.jar'
   ```

### WSL2
WSL2 is **not** supported for the Unity Editor. Use native Linux or Windows.
