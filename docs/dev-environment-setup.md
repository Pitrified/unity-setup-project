# Development Environment Setup

## 1. Goal

Zero → working local Android build in **under one hour**, without surprises.

Mental model:

```
clone → install Unity 6 LTS via Hub → open → run on device
```

---

## 2. Required software (versions are pinned)

| Tool              | Version                    | Notes                                  |
| ----------------- | -------------------------- | -------------------------------------- |
| Unity Hub         | latest                     |                                        |
| Unity Editor      | **6000.0 LTS** (Unity 6 LTS) | Exact patch version in `ProjectSettings/ProjectVersion.txt` |
| Android Build Support module | matching editor   | Install via Hub                        |
| Android SDK + NDK | bundled with module        | Use Unity-bundled, do not mix with Android Studio's SDK unless you know what you're doing |
| OpenJDK           | bundled with module        |                                        |
| Visual Studio Code | latest                    |                                        |
| Git               | ≥ 2.40                     |                                        |
| Git LFS           | ≥ 3.4                      | **Required.** See [git-workflow.md](git-workflow.md) |
| .NET SDK          | 8.0+                       | For `dotnet build` of asmdefs outside Unity |

VS Code extensions (recommended):

- C# Dev Kit
- Unity (by Unity Technologies)
- GitHub Copilot + Copilot Chat
- EditorConfig for VS Code

---

## 3. First clone

```bash
git lfs install                # one-time, machine-wide
git clone <repo-url>
cd artificial-pi
git lfs pull                   # ensure binary assets are real files, not pointers
```

If the project opens with corrupt textures/models → `git lfs pull` was skipped.

---

## 4. Open in Unity

1. Unity Hub → **Add project from disk** → select the cloned folder.
2. Hub will show the required Editor version. Install it if missing.
3. Open. First import takes several minutes.

Expected on first open:

- 0 console errors.
- 0 missing script warnings.
- Boot scene auto-loads.

---

## 5. Local play loop (Editor)

1. Open `Assets/Scenes/Boot.unity`.
2. Press Play.
3. Bootstrap → Persistent → Menu → Game flow runs.

If you opened `Game.unity` directly, use the editor helper
**Tools → Load Persistent Scene** (provided in `Game.Editor` asmdef) before pressing Play.

---

## 6. Local Android build

One-time:

1. Enable Developer Options on device, then USB debugging.
2. `adb devices` shows your device.
3. Copy `build.env.example` → `~/.config/artificial-pi/build.env`, fill in
   debug keystore values (debug keystore is auto-generated by Unity on first build).

Per-build:

```
./Tools/build-android.sh dev
adb install -r Build/dev.apk
adb logcat -s Unity:V
```

---

## 7. Validation checklist (run after setup)

- [ ] `git lfs ls-files` lists at least one asset
- [ ] Unity opens with 0 errors
- [ ] EditMode tests run and pass: **Window → General → Test Runner → Run All**
- [ ] Editor Play loop reaches Game scene
- [ ] `./Tools/build-android.sh dev` produces `Build/dev.apk`
- [ ] APK installs and launches on device
- [ ] `adb logcat -s Unity:V` shows no `[Error]` lines during one demo loop

---

## 8. Common issues

| Symptom                                     | Likely cause / fix                                   |
| ------------------------------------------- | ---------------------------------------------------- |
| Pink/purple materials                       | URP not active or shaders not imported → Reimport All |
| Files show as text pointers (`oid sha256:`) | `git lfs pull` not run                               |
| Build fails with "Gradle"                   | Reinstall Android module via Unity Hub               |
| `adb` doesn't see device                    | USB debugging off, wrong cable, missing OEM driver   |
| "Multiple precompiled assemblies"           | Duplicate package in `Packages/manifest.json`        |
| Long iteration on script change             | Missing `.asmdef` boundary - see [project-structure.md](project-structure.md) |

---

## 9. Optional: Linux / WSL notes

- Unity 6 LTS supports Linux Editor (Ubuntu 22.04 LTS recommended).
- Android tools work on Linux; ensure `udev` rules for ADB.
- WSL2 is **not** supported for the Editor; use native Linux or Windows.

---

## 10. Future improvements

- `Tools/setup.sh` that installs LFS hooks, copies `build.env.example`, verifies tooling.
- Devcontainer for headless CLI builds (no Editor).
