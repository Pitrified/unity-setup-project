# Water

Started 2026-11-18, unsupervised overnight, on the user's go:

pick a middle ground. Not the super basic we had with the wave color. Not a slop game blocky version. On the other hand, not a triple A game photorealistic.
So decent and reactive to physics (ships, cannonballs, waves lapping on island) but not something that burns a phone."

## What was there

artificial-pirate's `SG_Water.shader` (left the guide in `02_guide_rebuild`): a hand-written URP shader, sine waves in the vertex stage colouring by height, no lighting model to speak of, nothing on the CPU side, nothing reacting to anything.

## Research, 2026-11-18

Sources: Unity's Boat Attack demo (URP, a Gerstner water package with CPU buoyancy), the Crest docs (CPU or GPU displacement queries), Alexander Ameye's stylized water notes (depth-driven colour and foam), the Unity nature-shaders blog (script-updated render textures in a shader), store pages of Stylized Water 3, Crest URP, UWS 2, Poseidon, KWS.

| Approach | What it gives | Cost on a phone | Fit |
| -------- | ------------- | --------------- | --- |
| Scrolling textures on a flat plane | moving colour, no shape | trivial | the "super basic" end |
| Low-poly faceted waves | stylized, blocky | cheap | the "blocky" look the user ruled out |
| **Gerstner sum in the vertex shader, same function in C#** | real wave shape, crests, things float on the visible surface | a few k vertices, a handful of sin/cos per vertex | **the common middle**: Boat Attack, Crest's Gerstner mode, most mobile boat games |
| FFT ocean (Crest, HDRP Water) | realistic open sea | compute shaders, large textures | AAA end; HDRP-only in Unity's own package |
| Depth texture for shore colour and foam | shallow/deep colour, foam where water meets anything | an extra depth copy each frame on URP mobile (off in this project's Mobile asset) | common on desktop |
| **Baked seabed depth map** | the same shore colour and foam for static shores; readable on the CPU | one texture sample | **mobile-friendly variant** |
| Planar reflections | mirror reflections | renders the scene twice | too much for a phone |
| **Sky/probe reflection with Fresnel** | the sky in the water at grazing angles | cheap | standard |
| **Ripple height field in a small render texture** (CustomRenderTexture, double-buffered wave equation) | wakes, splashes, rings | a 256x256 update per frame | the usual interactive-water trick |
| Paid assets (Stylized Water 3, Crest, UWS 2, KWS) | all of the above, polished | varies | not in a public template; the rules forbid new packages unless a plan says so |

## Choice

The middle ground, built here, no packages:

- **Waves**: a sum of four Gerstner waves from one settings asset; the shader displaces the vertices, `WaveField` in C# evaluates the same sum, and one component pushes the parameters and a shared clock to the shader, so the CPU and the GPU cannot drift.
- **Shading**: shallow-to-deep colour and shore foam from a **baked seabed depth map**; a tiling normal map generated by a builder script; Fresnel to the sky; a sun highlight; crest foam where the waves pinch.
- **Floating**: a `Buoyancy` component on rigidbodies, sampling `WaveField` at a few points; drag in the water; heavy things sink.
- **Interaction**: a ripple simulation in a CustomRenderTexture around the action; moving floaters leave wakes, impacts splash; ripples are visual (the CPU does not see them).
- **Shore**: foam bands moving up the depth gradient, so waves read as lapping on the island.
- **Scene**: the sample's flat ground becomes an island with a beach, sea around it; barrels and a few buoys float; a demo launcher lobs cannonballs into the water.
- **Budget**: water mesh about 20 k triangles, one transparent draw for the surface, one 256x256 ripple update, no depth or opaque texture.

## Out of scope

- Underwater rendering, caustics, refraction (no opaque texture), planar reflections.
- Wave damping by depth on the CPU side (foam bands carry the shore); an upgrade if floaters near the beach need it.
- artificial-pirate's water; it can copy this when it wants to.
